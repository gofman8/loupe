# Every file that may lower the `unsafe_code` lint, with its reason.
# ci/check.sh (gate_unsafe_allow in ci/gates.sh) fails on a file that
# can carry unsafe code without a line here, and on a stale line. A file
# can carry unsafe code when its code (comments and strings stripped)
# contains the `unsafe` keyword, or it lowers the `unsafe_code` lint.
# `unsafe` in Loupe marks two things: memory-unsafe operations (only
# volatile.rs) and security contracts the compiler cannot check
# (minting a provenance label), as `unsafe trait Send` does in std.
# Format: <path> <reason>.
